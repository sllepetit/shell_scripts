ENGLISH

Application..: atualiza.sh
Purpose......: Operating system update with logging
Authors......: Sydnei Lucchesi Le Petit / Gemini
Created......: October 17, 2026
Updated......: 10/26/2026
Operational Steps:
1. Prompts for confirmation to run the routine
   If the choice is YES:
2. DIRECTORY AND LOG CONFIGURATION (Industry standard practice)
   DEFINITION OF COLORS AND SYSTEM VARIABLES FOR ON-SCREEN DISPLAY
   INITIATING MAINTENANCE ROUTINES
3. UPDATES THE PACKAGE LIST AND REPOSITORY INFORMATION REGISTERED IN THE LINUX INSTALLATION, WITHOUT MAKING ANY CHANGES
4. UPDATES PACKAGES FROM THE OFFICIAL REPOSITORIES REGISTERED IN THE LINUX INSTALLATION
5. CLEANS UP UNNECESSARY DEPENDENCIES
6. REMOVES CACHED FILES AND PACKAGES
7. EMPTIES THE TRASH/RECYCLE BIN
8. COMPLETES EXECUTION AND VERIFIES THE LOG
9. CLEANS THE HDD/SSD WHERE THE SYSTEM IS INSTALLED - TO BE IMPLEMENTED VIA CRONTAB

PORTUGUESE

Aplicação..: atualiza.sh
Propósito..: Atualização do sistema operacional com log
Autores....: Sydnei Lucchesi Le Petit / Gemini
Criação....: 17 de outubro de 2026
Atualização: 26/10/2026
Etapas de Funcionamento:
1. Aguarda a opção de execução ou não da rotina 
   Se a opção for SIM
2. CONFIGURAÇÃO DE DIRETÓRIOS E LOGS (Prática de mercado)
   DEFINIÇÃO DE CORES E VARIÁVEIS DO SISTEMA PARA APRESENTAÇÃO EM TELA
   INICIANDO AS ROTINA DE MANUTENÇÃO
3. ATUALIZA A LISTA DE PACOTES E AS INFORMAÇÕES DOS REPOSITÓRIOS CADASTRADOS NA INSTALAÇÃO DO LINUX, SEM PROMOVER QUALQUER ALTERAÇÃO
4. ATUALIZA OS PACOTES A PARTIR DOS REPOSITÓRIOS OFICIAIS CADASTRADOS NA INSTALAÇÃO DO LINUX
5. LIMPA AS DEPENDÊNCIAS DESNECESSÁRIAS
6. REMOVE ARQUIVOS E PACOTES EM CACHE
7. ELIMINA ARQUIVOS DA LIXEIRA
8. FINAL DA EXECUÇÃO COM CONFERÊNCIA DO LOG
9. LIMPA O HDD/SSD ONDE ESTÁ INSTALADO O SISTEMA - A SER IMPLEMENTADO NO CRONTAB
